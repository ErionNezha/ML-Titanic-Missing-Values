# 🚢 Titanic — Trajtimi i Vlerave Munguese

Udhëzues praktik për trajtimin e vlerave munguese (NaN) në Machine Learning, mbi dataset-in Titanic (174 nga 850 mosha mungojnë): imputim me mesore, vlerë arbitrare, fundi i shpërndarjes, indikator NaN, kategoria më e shpeshtë dhe one-hot encoding. Demo-ja ndërvepruese tregon efektin e secilës metodë në histogramin real të moshave.

## 🚀 Si ta hapësh

Hap `index.html` — tab-i **Live Demo** ekzekutohet direkt në browser, ndërsa tab-i **Kodi Burim** tregon kodin e plotë (demo + origjinali i paprekur).
